# PhoneMic: 手机局域网麦克风 (Android 手机 -> Windows 电脑)

**PhoneMic** 是一个高保真、极低延迟（< 20ms）、零重传积压的局域网麦克风音频传输系统。让你的 Android 手机变成电脑的高保真无线上网课、会议办公、游戏开黑麦克风。

---

## 🌟 核心特性与架构升级

- **⚡ 硬件级异步回调引擎（Callback Engine）**：
  - 电脑端采用专业音频硬件回调驱动，UDP 接收线程与声卡播放彻底解耦；
  - 极小环形队列（最多仅保留 40ms 数据），发生网络抖动时强制秒弃过期旧帧，**彻底杜绝延迟累积，将端到端延迟死锁在 15~20 毫秒（完全人体无感级别）**。
- **🎙️ 全频段清晰人声（VOICE_RECOGNITION）**：
  - 手机端采用高清晰度语音源采集，人声中高频细节饱满通透，杜绝低通滤波变声与沉闷感；
  - 避免触发 Android 系统的 VoIP 电话模式，手机连接电脑蓝牙时绝不产生串音回路。
- **🔊 智能双声道立体声映射（Stereo Broadcast）**：
  - 电脑端将单声道 PCM 自动无损镜像至双声道缓冲区，确保 48,000 Hz 基频精准复原，完美匹配 VB-CABLE 驱动架构。
- **全系统软件无缝识别**：
  - 配合成熟虚拟声卡（**VB-Audio Virtual Cable**），在 Windows 系统各软件（微信、QQ、Discord、腾讯会议、OBS、各类游戏等）中直接作为真实物理麦克风选择。
- **三重极速配对机制**：
  1. **局域网 UDP 自动发现**：App 启动自动探测局域网内的电脑端，一键秒连；
  2. **终端 ASCII 二维码扫码**：电脑端启动即在终端打印专属二维码，App 扫码即连；
  3. **手动 IP / 端口输入**：复杂跨子网或隔离网络兜底。
- **原生 Android 硬件级控制**：
  - **前台常驻服务 (Foreground Service)**：支持熄屏与后台稳定持续收音，通知栏带有一键静音与断开控制；
  - **麦克风增益调节 (0% ~ 200%)**；
  - **实时分贝 (dBFS) 电平波形显示**，声学状态一目了然。
- **清爽极简终端仪表盘**：
  - 双击秒启，静默自动锁定虚拟声卡，直接呈现精简的二维码与实时音量分贝仪表盘，零冗余日志。

## 🚀 极速上手指南

### 第一步：电脑端准备（虚拟声卡）

1. 下载并安装免费通用的虚拟声卡驱动：
   - 官方免费下载地址：[VB-Audio Virtual Cable](https://vb-audio.com/Cable/)
   - 安装完成后，电脑会生成：
     - **CABLE Input**：声音灌入口（供电脑后台服务注入音频）；
     - **CABLE Output**：麦克风收音口（供第三方软件当作麦克风使用）。

### 第二步：启动电脑端服务

1. 在项目根目录下，双击运行：
   👉 [`启动电脑端服务.bat`](file:///F:/PhoneMic/启动电脑端服务.bat)
2. 程序会自动检测网络与最佳虚拟音频通道，并在终端显示专属配对二维码与实时音量仪表盘。

### 第三步：手机端安装与连接

1. 将项目根目录下的 [`PhoneMic.apk`](file:///F:/PhoneMic/PhoneMic.apk) 安装到安卓手机并打开；
2. 确保手机与电脑连接至**同一个 Wi-Fi 局域网**；
3. 点击“**扫码配对**”对准电脑终端屏幕上的二维码，或点击“**局域网探测**”自动发现电脑，点击秒连！

### 第四步：在电脑各应用中选用麦克风

在微信、QQ、Discord、腾讯会议、游戏或 OBS 设置中：
- **【输出设备 / 扬声器】**：保持选择您平时的 **扬声器 (Realtek)** 或 **耳机**（电脑正常放歌、游戏声音）；
- **【输入设备 / 麦克风】**：选择 **`CABLE Output (VB-Audio Virtual Cable)`**。
- 现在对着手机说话，对方即可听到极度清晰、超低延迟的手机麦克风声音！

## 💡 常见问题与优化小贴士

### 1. 为什么“声音输出”列表里会出现 `CABLE Input`？
VB-CABLE 本质是一根虚拟音频对录线，Python 后端需要把声音灌入它的输入口（`CABLE Input`），各软件才能从输出口（`CABLE Output`）录到声音。
- **如何清理多余项**：按 `Win + R` 输入 `mmsys.cpl` 打开声音控制面板，在【播放】列表里右键多余的 `CABLE In 16ch` 点击**【禁用】**即可将其彻底从任务栏列表中消除。
- 只要确保系统默认播放设备是您的物理扬声器/耳机，电脑本身声音就绝不会受到任何影响。

### 2. 为什么实时电平显示为负数？
这是专业数字音频工程中的标准 **dBFS（满量程分贝）**：
- `0 dB` 为数字音频极限红线（超过即破音失真）；
- `-12 dB ~ -18 dB` 为平时说话最饱满、最清晰的黄金区间；
- 所有正常音频数值均处于 `0 dB` 以下的负数范围。
